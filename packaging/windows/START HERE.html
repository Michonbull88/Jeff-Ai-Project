YOUR LOCAL LEARNING ASSISTANT

JEFF, ready for Windows.

This folder contains the complete application, all four courses, the current local AI model, the English speech model and the disk archive of saved answers.

1. Copy the whole folder

If you used the ZIP, right-click it and choose Extract All. Put the extracted folder somewhere permanent, for example C:\JEFF or your Documents folder. Open the folder that contains the two numbered command files.

This package targets an Intel/AMD 64-bit PC running Windows 11 or Windows 10 version 22H2. Allow around 10 GB of free space for the folder and the installed runtimes. First setup needs internet; local lessons, AI answers and speech recognition work offline after setup. Links, live weather and browser recognition fallback still need internet.

2. Install three free programs once

  1. Node.js LTS — choose the Windows x64 installer. Keep the option to add Node.js to PATH.
  2. Python 3.13, Windows installer (64-bit) — include the Python launcher and tick Add Python to PATH. JEFF creates its own Python environment.
  3. Ollama for Windows — install normally. JEFF's AI model is already in this folder.

Use Chrome or Edge to open JEFF. Close and reopen the setup window after installing these programs so it can find them.

3. Set up, then start

  1. Double-click 1 - SETUP JEFF.cmd. Wait for Setup complete. It installs Windows-compatible packages and prepares speech recognition.
  2. Double-click 2 - START JEFF.cmd. JEFF opens at http://127.0.0.1:3000.
  3. Keep the command window open while using JEFF. To stop, press Ctrl+C in that window.

For later visits, just use 2 - START JEFF.cmd. Click the microphone and allow browser access when you want to speak. Choose a local English voice in Windows if read-aloud is unavailable.

4. Bring your browser progress

On the original Mac, open JEFF's Backup & Transfer page in the browser you normally use. Click Download JEFF backup and copy that JSON file into this transfer folder or onto your USB drive.

On Windows, start JEFF, open the same Backup & Transfer page, choose the JSON file and click Restore this backup. This brings completed lessons, notes, saved tutor conversations, drafts, playground code and preferences. Use the same site address as your lessons when exporting; localhost and 127.0.0.1 have separate browser storage.

JEFF's disk archive of saved answers is already included. A main-assistant conversation that existed only in an open tab cannot be recovered from disk.

If something needs attention

  • A program is missing: install the matching program above, close the command window, and run setup again.
  • Setup cannot download packages: check internet access and run setup again. Do not copy the Mac's node_modules or Python environment.
  • A port is in use: close the other JEFF window or the application using port 3000 or 11435, then retry. This launcher does not stop other applications.
  • Local speech is unavailable: rerun setup. The speech environment must be created on this computer. If you move this folder again later, rerun setup in its new location.
  • Windows blocks a downloaded file: inspect the file and follow your computer's security policy. No system-wide execution-policy changes are required.
JEFF uses this folder's model files on local port 11435 and serves the app on local port 3000. Paid OpenAI features and Ollama cloud are disabled by the launcher. The transfer excludes API keys and computer-specific caches. Sources: Ollama Windows requirements, Node.js downloads, Python Windows downloads. Prepared 7 October 2026.
